# 股票绝对估值

基于自由现金流贴现模型（DCF），估算公司的绝对价值（合理股票价值）。

## 核心原理

价值源自未来流入的现金流，将未来各期自由现金流以一定折现率折算回现在加总，即得到公司估值。

## 计算模型

统一符号约定：
- V = 公司估值
- FCF₀ = 基期（当前）自由现金流
- FCFₜ = 第 t 年自由现金流
- r = 折现率
- g = 自由现金流年增长率（g₁ 第一阶段，g₂ 第二/过渡阶段，g₃ 第三/稳定阶段）
- n = 第一阶段年数，m = 第二阶段年数（三阶段模型）
- TV = 终值

### 模型一：零增长模型

适用于成熟稳定、没有增长的公司，每年自由现金流保持稳定水平。

```
V = FCF / r
```

### 模型二：永续增长模型

适用于成熟公司，未来自由现金流以非常缓慢且不变的速度永续增长。

```
V = Σ FCF₀(1+g)^t / (1+r)^t  (t=1→∞)
  = FCF₀ × (1+g) / (r-g)
  = FCF₁ / (r-g)
```

约束：r > g，否则公式无意义。

### 模型三：两阶段模型

时间分为两阶段：第一阶段为详细预测期（通常 3-5 年，增长率 g₁），第二阶段为终值期（永续增长率 g₂）。

```
V = Σ FCF₀(1+g₁)^t / (1+r)^t                    (t=1→n，第一阶段现值)
  + FCF_n(1+g₂) / [(r-g₂)(1+r)^n]               (终值折现)
```

其中 FCF_n = FCF₀(1+g₁)^n。约束：r > g₂。

### 模型四：三阶段模型

公司经历三个阶段：成长阶段（增长率最高）、过渡阶段（逐渐下降）、稳定阶段（低增长率永续）。

```
V = Σ FCF₀(1+g₁)^t / (1+r)^t                    (t=1→n，成长阶段)
  + Σ FCF_n(1+g₂)^(t-n) / (1+r)^t               (t=n+1→m，过渡阶段)
  + FCF_m(1+g₃) / [(r-g₃)(1+r)^m]               (稳定阶段终值)
```

其中 FCF_n = FCF₀(1+g₁)^n，FCF_m = FCF_n(1+g₂)^(m-n)。约束：r > g₃。

## 执行流程（必须严格遵守）

### 第一步：收集信息，澄清缺失项（关键！）

用户请求估值时，先对照所选模型检查必备参数清单：

| 模型 | 必备参数 |
|------|---------|
| 零增长 | FCF₀、r |
| 永续增长 | FCF₀、r、g |
| 两阶段 | FCF₀、r、g₁、g₂、n |
| 三阶段 | FCF₀、r、g₁、g₂、g₃、n、m |

**规则：**
1. 用户没有明确说出模型 → 必须询问选择哪个模型，并简要说明四个模型的适用场景供用户选择。
2. 用户没有给出某个参数（包括折现率、增长率、年数）→ 必须逐项询问，禁止自行假设或采用"行业常用值"。
3. 用户只给了部分参数 → 列出已有参数和缺失参数清单，一次性向用户要齐。
4. 参数含义有歧义（如"增长率15%"没说明是哪个阶段）→ 必须先澄清再计算。
5. 只有当用户明确给出全部参数后，才能进入计算。任何"我先用X%算一下"的擅自行为都是违规的。

### 第二步：合理性检查

计算前检查参数，发现以下情况必须向用户指出并确认，不可静默修正：
- r ≤ g（永续/终值阶段）：公式无意义，估值发散
- 增长率明显异常（如永续增长率 > 折现率、第一阶段增长率超过 50%）
- n 或 m 超出常规范围（第一阶段通常 3-5 年）

### 第三步：计算

运行 `scripts/valuation.py`（本 skill 目录下）完成计算，避免手算误差：

```bash
python3 <skill目录>/scripts/valuation.py <模型> \
  --fcf0 <基期FCF> --r <折现率> \
  [--g <g>] \
  [--g1 <g1> --g2 <g2> --n <年数>] \
  [--g3 <g3> --m <年数>]
```

模型取值：`zero`（零增长）/ `perpetuity`（永续增长）/ `two-stage`（两阶段）/ `three-stage`（三阶段）。

增长率、折现率可写 `0.15` 或 `15%`。FCF 单位随用户输入（万元/亿元均可，估值结果同单位）。

若因环境原因无法运行脚本，则手动逐项计算，但必须展示每一步中间值。

### 第四步：汇报结果

输出内容必须包含：
1. **模型与参数回顾**：用户选定的模型和全部参数（原样列出）
2. **逐步计算过程**：
   - 两/三阶段模型：逐年列出 FCFₜ、折现因子 1/(1+r)^t、各年现值
   - 终值计算：TV 及其现值
   - 各部分加总
3. **最终估值**：V = 数值 + 单位（与 FCF 输入单位一致）
4. **从公司价值到股票价值（如需要）**：
   - 股权价值 = 公司价值 - 债务价值
   - 每股价值 = 股权价值 / 总股本
   - 若用户提供了债务、股本数据则一并计算；未提供则提示用户补充，**同样不得自行假设**
5. **敏感性提示（可选）**：提醒估值对 r 和 g 高度敏感，建议用户提供参数区间做多情景演算

## 经营自由现金流的口径说明

若用户询问 FCF 怎么取值，按《运用自由现金流贴现模型进行股票估值》的口径提示：

经营资产自由现金流量 = 息税前利润 × (1-所得税税率) + 折旧及摊销 + 其他非现金成本费用 - 保全性资本支出

其中保全性资本支出的估算：
保全性资本支出 = 长期经营资产减值损失 + 信用减值损失 + 固定资产折旧、油气资产折耗、生产性生物资产折旧、使用权资产折旧 + 无形资产摊销 + 长期待摊费用摊销 + 处置长期资产的损失 + 固定资产报废损失

简化口径：经营资产自由现金流量 = 经营活动现金流量净额 - 保全性资本支出。

注意：这是提示性参考信息，具体取数口径由用户决定。
